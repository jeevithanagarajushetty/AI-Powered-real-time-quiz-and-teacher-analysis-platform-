Python Programming

Python is a high-level, interpreted programming language known for its simplicity and readability. It was created by Guido van Rossum and first released in 1991. Python supports multiple programming paradigms including procedural, object-oriented, and functional programming.

Key features of Python:
1. Simple and easy to learn syntax
2. Dynamic typing
3. Automatic memory management
4. Large standard library
5. Cross-platform compatibility

Python is widely used in:
- Web development (Django, Flask)
- Data science and machine learning
- Artificial intelligence
- Automation and scripting
- Desktop applications

The most common data types in Python are:
- Integers (int)
- Floating point numbers (float)
- Strings (str)
- Lists (list)
- Dictionaries (dict)
- Tuples (tuple)
- Sets (set)

Python uses indentation to define code blocks, unlike other languages that use braces. This makes Python code more readable and consistent.
